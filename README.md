### Description

Forward Backward Self-Assembly artificial neural network (FBSAANNpt) for PyTorch - experimental 

### License

MIT License

### Installation
```
conda create -n pytorchsenv
source activate pytorchsenv
conda install python
pip install datasets
pip install torch
```

### Execution
```
source activate pytorchsenv
python ANNpt_main.py
```
